# 義大利10日行程動態軌跡地圖與法國暴動外溢警戒導航
(Italy Tour 2026 Animated Map & Riot Alert System)

本專案提供雄獅旅遊義大利10日行程（2026/11/03 - 2026/11/12）之動態時序地圖、各晚入住飯店導航、名勝打卡點，以及法國生活成本與學運抗議波及義大利（尤其是米蘭大教堂商圈）的各站風險評估與防範指引。

---

## [線上即時互動地圖] (GitHub Pages)

本儲存庫可直接啟用 GitHub Pages，隨時使用手機或電腦瀏覽器打開即可觀看動態動畫與安全儀表板：
👉 **[點此開啟線上動態地圖動畫](https://genius2plus.github.io/italy-travel-map-2026/)**

### 功能特點：
- **動態時間軸（Timeline）巡航**：播放/暫停/跳速（0.5x ~ 3x），自動沿旅遊路線推進。
- **法國動亂外溢震波動畫**：直觀視覺化法國生活成本抗爭越過阿爾卑斯邊境擴散至米蘭的動態脈衝。
- **即時情資 HUD**：第 7 天（11/09 米蘭）自動亮起紅色高警戒警示，提醒自由活動防護原則；第 5 天（多洛米蒂）轉為綠色安全。

## [Google Maps 與 Google Earth 專用地圖檔]

本倉庫附帶多種格式的地理資料，供隨團出國導航使用：

1. **`italy_travel_and_riot_map.kml`**
   - **用途**：匯入 **Google My Maps (我的地圖)**。
   - **內容**：包含確認入住的 6 間飯店、米蘭/羅馬維安管制區、熱門景點與駐義大利代表處緊急求助電話。
   - **匯入教學**：進入 [Google My Maps](https://www.google.com/mymaps) ➔ 建立新地圖 ➔ 匯入此 KML 檔案 ➔ 即可在手機 Google Maps APP「已儲存」中開啟！

2. **`italy_google_earth_animated_tour.kml`**
   - **用途**：匯入 **Google Earth (Google 地球)**。
   - **內容**：內建 `<gx:Tour>` 3D 鏡頭導覽。點擊「播放導覽」即可享受無人機視角俯衝飛巡全義大利十日名勝與米蘭警戒區！

3. **`italy_travel_and_riot_map.geojson`**
   - **用途**：支援 Maps.me、OsmAnd、QGIS 等各大離線地圖與 GIS 工具。
